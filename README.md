# AI-Integrated Industrial Education: Vibe Coding Project Class

## 1. 개요 (Course Overview)
- **과목명**: AI 기반 교육 및 프로젝트 개발 (Vibe Coding w/ Antigravity)
- **대상**: 교육대학원 컴퓨터응용교육특론 수강자
- **기간**: 15주 (주 2시간)
- **학습 목표**: 
  1. 최신 협업 및 지식 관리 도구(Notion, GitHub)의 실무적 활용 능력을 배양한다.
  2. AI 코딩 에이전트(Antigravity)를 활용하여 코딩 비전공자도 자신의 아이디어를 소프트웨어로 구현하는 능력을 갖춘다.
  3. 전공(기술, 전기전자정보통신, 기계, 건설, 화학 등)과 관련된 교육용 도구 또는 실무용 웹 애플리케이션을 스스로 기획하고 개발한다.

## 2. 활용 도구 (Tools)
1.  **Notion**: 프로젝트 기획, 일정 관리, 아카이빙, 포트폴리오 제작.
2.  **GitHub**: 소스 코드 버전 관리, 협업, 결과물 배포 (GitHub Pages).
3.  **Antigravity (AI Agent)**: 자연어 프롬프트를 통한 코드 생성, 디버깅, 리팩토링, 페어 프로그래밍.

## 3. 주차별 강의 계획 (Weekly Syllabi)

### Part 1: 디지털 협업 기초 및 AI 코딩 입문 (Weeks 1-4)
기초적인 디지털 리터러시를 다지고, AI와 함께하는 코딩의 개념(Vibe Coding)을 익힙니다.

| 주차 | 주제 | 세부 내용 | 실습/과제 |
| :-- | :--- | :--- | :--- |
| **1주** | 오리엔테이션 및 AI와 교육 | - 수업 소개 및 평가 기준 안내<br>- 제4차 산업혁명과 공업 교육의 변화<br>- 생성형 AI와 코딩의 미래 (Antigravity 소개) | - Notion 계정 생성 및 자기소개 페이지 만들기 |
| **2주** | 스마트한 지식 관리: Notion | - Notion 기본 사용법 (Page, Block, Database)<br>- 프로젝트 관리를 위한 템플릿(Kanban, Calendar) 제작<br>- 교육 자료 아카이빙 전략 | - 나만의 학습 대시보드 구축하기 |
| **3주** | 협업과 버전 관리: GitHub | - Git과 GitHub의 이해 (Repository, Commit, Push)<br>- Desktop GUI 도구 활용법<br>- 오픈 소스 생태계와 공업 교육 자료 탐색 | - GitHub 저장소 개설 및 Notion과 연동하기 |
| **4주** | AI 코딩 에이전트 시작하기 | - Antigravity 설치 및 환경 설정 (VS Code 연동 등)<br>- 프롬프트 엔지니어링 기초: "어떻게 말해야 코드를 잘 짜줄까?"<br>- Hello World부터 간단한 스크립트 생성까지 | - Antigravity로 간단한 계산기 프로그램 만들기 |

### Part 2: AI 활용 웹 애플리케이션 개발 (Weeks 5-8)
실제 웹 기술(HTML/CSS/JS)을 AI의 도움을 받아 학습하고, 전공 관련 도구를 만들어봅니다.

| 주차 | 주제 | 세부 내용 | 실습/과제 |
| :-- | :--- | :--- | :--- |
| **5주** | 웹의 기초와 디자인 (HTML/CSS) | - 웹 페이지 구조 이해 (Dom)<br>- CSS로 스타일링하기 (반응형 디자인 맛보기)<br>- Antigravity를 활용한 UI 컴포넌트 생성 | - 개인 프로필 및 포트폴리오 웹사이트 메인 화면 제작 |
| **6주** | 인터랙티브 웹 구현 (Javascript) | - 자바스크립트 기초 문법과 로직<br>- 동적인 기능 구현 (버튼 클릭, 데이터 입력 등)<br>- AI 에이전트와 함께 로직 디버깅하기 | - 단위 변환기(공학용) 또는 교육용 퀴즈 앱 만들기 |
| **7주** | 데이터 시각화 및 활용 | - CSV/Excel 데이터 웹에서 불러오기<br>- Chart.js 등을 활용한 공학 데이터 시각화<br>- 공업/기술 데이터(치수, 통계 등) 대시보드 구현 | - 전공 관련 데이터 시각화 프로토타입 제작 |
| **8주** | 중간 발표 및 프로젝트 기획 | - 개인별 프로젝트 아이디어 제안 (전공 연계)<br>- 기획안 발표 및 동료 피드백<br>- Notion에 프로젝트 로드맵 수립 | - 프로젝트 기획서(Notion) 및 초기 구조 잡기 |

### Part 3: 자기 주도 프로젝트 (Capstone Project) (Weeks 9-14)
학생 스스로 전공과 관련된 문제를 해결하거나 교육에 활용할 수 있는 웹 서비스를 개발합니다.

| 주차 | 주제 | 세부 내용 | 실습/과제 |
| :-- | :--- | :--- | :--- |
| **9주** | 프로젝트 착수 및 MVP 개발 1 | - 개발 환경 세팅 및 프로젝트 구조화<br>- 핵심 기능(Core Feature) 정의 및 우선순위 선정<br>- Antigravity와 페어 프로그래밍 (Pair Programming) | - 프로젝트 저장소 생성 및 핵심 기능 1차 구현 |
| **10주** | MVP 개발 2: 기능 구현 | - 복잡한 로직 및 데이터 처리 구현<br>- 에러 핸들링 및 예외 처리<br>- AI를 활용한 코드 최적화 및 리팩토링 | - 핵심 기능 동작 가능한 MVP(최소 기능 제품) 완성 |
| **11주** | UI/UX 디자인 고도화 | - 사용자 경험(UX) 개선을 위한 인터페이스 디자인<br>- 모바일 반응형 적용 및 스타일 폴리싱<br>- 애니메이션 및 시각적 효과 추가 | - 사용자 친화적인 UI 적용 완료 |
| **12주** | 테스트 및 배포 (Deployment) | - 브라우저 크로스 테스팅<br>- GitHub Pages를 이용한 정적 웹 호스팅<br>- 도메인 연결 및 SEO 기초 | - 웹 서비스 배포 및 링크 공유 |
| **13주** | 문서화 및 사용 설명서 | - Readme.md 작성법 (프로젝트 소개, 설치법)<br>- Notion을 활용한 사용자 가이드/매뉴얼 제작<br>- 포트폴리오 정리 | - 프로젝트 문서화 완료 |
| **14주** | 최종 점검 및 동료 리뷰 | - 최종 결과물 점검 (Quality Assurance)<br>- 상호 테스트 및 피드백 (버그 찾기)<br>- 발표 자료 준비 | - 최종 결과물 수정 및 발표 준비 |

### Part 4: 종합 평가 (Week 15)

| 주차 | 주제 | 세부 내용 | 실습/과제 |
| :-- | :--- | :--- | :--- |
| **15주** | 최종 성과 발표회 (Demo Day) | - 프로젝트 최종 시연 및 발표<br>- 개발 과정에서의 회고 (AI 활용 경험 등)<br>- 향후 교육 현장/산업 현장 적용 방안 토의 | - 최종 프로젝트 제출 및 상호 평가 |

## 4. 평가 방법
- **출석 및 참여도 (20%)**: 수업 참여 및 실습 수행 태도
- **중간 기획 (30%)**: 프로젝트 기획안의 독창성 및 실현 가능성 (Notion 활용)
- **기말 프로젝트 (50%)**: 
    - 최종 결과물의 완성도 (40%)
    - 문서화 및 코드 관리 (GitHub/Readme) (30%)
    - AI 도구 활용 능력 및 문제 해결 과정 (30%)
